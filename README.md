# 内容推送（Content Pusher）

站间内容推送插件：把**本地发送站**的文章、评论（含 AI 已生成的评论）、话题推送到**目标生产站**。

## 核心设计

- **目标站零插件**：只用 WordPress 核心 REST API（`wp/v2`）+ 应用密码（WP 5.6+ 核心功能）。
  目标站不需要安装本插件，也不需要安装任何其他插件，只负责"接收内容"。
- **本地是发送站，目标站是生产站**：插件只装在发送站一侧，单向推送（本地 → 生产）。
- **推送全程 HTTPS**：目标站地址强制 `https://`，请求强制校验证书（`sslverify=true`），不提供关闭开关。
- **话题"有相关插件才显示"**：话题按设置映射到目标站分类法或标签——
  目标站有 `abp_topic` 话题分类法（相关插件）时按话题推送并显示；
  没有时落为标签归档或不推送。**目标站自身决定显示什么**，本插件只负责把数据送过去。

## 推送内容

| 内容 | 说明 |
|------|------|
| 文章 | 标题、正文、摘要、别名（slug）、状态、日期、分类、标签、特色图、正文图片 |
| 评论 | 文章现有的**真实评论**，也包括 **AI 已生成的评论**（保留作者、邮箱、网址、时间、回复层级） |
| 话题 | 本地 `abp_topic` 术语 → 目标站 abp_topic 分类法或标签（可关） |

### 匹配规则（不重复建文）

1. 优先使用本地记录的远端文章 ID（`_cp_remote_id`）；
2. 无记录时按 **slug** 匹配目标站文章 → 同名即更新；
3. 仍未命中 → 新建。
评论同样按本地 ID 记录远端评论 ID（`_cp_remote_comment_id`），重推自动跳过已推评论。

### 图片同步

- 特色图与正文图片上传到目标站媒体库，正文 URL 自动重写为远端地址；
- 外部图片下载后转存目标站；
- 已传图片按附件 ID / URL 缓存（`cp_media_map`），不重复上传。

## 使用

1. 在**目标站**（生产站）后台：用户 → 个人资料 → 应用程序密码，生成一个（建议管理员账号，名称如 `content-pusher`）。
2. 在**本地发送站**安装并启用本插件。
3. 设置 → 内容推送：
   - 目标站地址（`https://…`，可粘贴 `/wp-json/` 完整地址，自动剥掉）；
   - 应用密码用户名 + 应用密码；
   - 点「测试连接」验证（同时探测目标站分类法，决定话题映射方式）；
   - 按需调整推送选项。
4. 推送入口：
   - **推送管理页**（内容推送 → 推送管理）：筛选/搜索文章 → 勾选 → 配置（同名查重 跳过/覆盖 + 可选 封面/摘要/评论/话题）→ 单篇一键 或 批量推送（后台排队）；
   - 文章列表「推送」列/行操作「推送到生产站」「推送评论」；
   - 文章编辑页侧边「内容推送」框；
   - 开启「自动推送」后，本地文章发布即自动排队推送（WP-Cron，不阻塞发布）。
5. 进度与排错：设置页「推送日志」查看；文章列表「推送」列显示 已推送/失败/评论进度。

## 设置项

| 设置 | 说明 |
|------|------|
| 目标站地址 | 必须 `https://` 开头；强制校验证书 |
| 应用密码用户名 / 应用密码 | 目标站核心功能生成，零插件 |
| 自动推送 | 本地发布后自动排队推送 |
| 远端状态 | 跟随本地 / 一律发布 / 一律草稿 |
| 评论推送 | 推送真实评论与 AI 已生成评论；可选含待审 |
| 话题推送 | 自动（有 abp_topic 用话题，否则标签）/ 一律标签 / 一律 abp_topic / 不推 |
| 同名查重 | 覆盖更新（默认）/ 跳过；推送管理页每次可临时切换 |
| 默认推送内容 | 封面 / 摘要 / 评论 / 话题（文章本体与分类标签始终推）；推送管理页每次可临时勾选 |
| 图片同步 | 特色图 + 正文图片上传与 URL 重写 |
| 超时 / 重试 | 单请求超时秒数、网络错误与 5xx 重试次数 |

## 数据存储

- 选项：`cp_settings`（设置）、`cp_log`（日志环形缓冲 300 条）、`cp_media_map`（媒体缓存）、`cp_term_map`（术语缓存）、`cp_target_taxonomies`（目标站分类法缓存）
- 文章 meta：`_cp_remote_id`、`_cp_remote_url`、`_cp_last_push`、`_cp_last_error`
- 评论 meta：`_cp_remote_comment_id`
- 卸载（uninstall.php）全部清理。
