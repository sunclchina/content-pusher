# 目标站兼容插件（星河话题）

文件：`content-pusher-target-compat.php`

**用途**：装在**目标站（生产站）**，恢复 thread 文章类型（星河AI工具箱话题帖）的 REST 创建权限。

**为什么需要**：星河AI工具箱注册 thread 类型时把 `create_posts` 显式设为 `false`（话题帖只能由星河自己的 AI 流程创建），
「内容推送」的「星河兼容」话题模式需要通过 REST 创建话题帖，因此需要此兼容插件放开权限。
仅恢复 REST 创建能力，不影响星河原有流程。

## 安装方式（任选其一）

1. **后台安装（推荐）**：将 `content-pusher-target-compat.zip` 上传到 插件 → 安装插件 → 上传插件 → 启用。
2. **文件方式**：把 `content-pusher-target-compat.php` 放到 `wp-content/mu-plugins/` 目录（自动生效，无需启用）。

## 验证

安装启用后，目标站后台 → 插件列表应显示「内容推送-目标站兼容（星河话题）」已启用；
然后在发送站设置页重新「测试连接」→ 话题模式选「星河兼容」→ 推送文章时即会创建话题帖（/thread/ 话题页）。
